18. Guía Práctica: DB Browser (SQLite) y XAMPP (MySQL)

Para trabajar cómodamente con bases de datos en Java necesitamos herramientas visuales que nos permitan diseñar tablas, cargar datos de prueba, verificar qué insertó nuestro programa y monitorear las conexiones activas. Aquí tienes la guía paso a paso de las dos herramientas utilizadas en clase: DB Browser for SQLite y XAMPP + phpMyAdmin.

Parte 1: Guía Completa de DB Browser for SQLite

DB Browser for SQLite (DB4S) es la herramienta visual gratuita para crear y administrar archivos de base de datos SQLite (.db o .sqlite).

Paso 1: Crear informacion.db en la Raíz del Proyecto

  1. Abre DB Browser y haz clic en Nueva base de datos (New Database).
  2. Navega hasta la carpeta raíz de tu proyecto Java (en el mismo nivel donde está el archivo pom.xml).
  3. Nómbrala exactamente informacion.db y guarda. Así, la ruta relativa jdbc:sqlite:informacion.db la encontrará sin depender de rutas absolutas como C:\Users\....

Paso 2: Diseñar las Tablas Visualmente

  1. Se abrirá la ventana Editar definición de la tabla. Escribe el nombre VariedadCafe.
  2. Haz clic en Añadir (Add) para agregar campos:
    • IDVariedad → Tipo: INTEGER → Marca casillas NN (Not Null), PK (Primary Key) y AI (Autoincrement).
    • Descripcion → Tipo: TEXT → Marca casilla NN.
  3. Repite el proceso para la tabla Cafe y, en la columna VariedadCafe, haz doble clic en la columna Clave Foránea (Foreign Key) y selecciona VariedadCafe(IDVariedad).

Las 4 Pestañas de DB Browser que Usarás a Diario

1. Estructura de la BD

Muestra la lista de tablas, índices, vistas y triggers. Desde aquí puedes crear, modificar o eliminar tablas.

2. Hoja de Datos (Browse Data)

Permite elegir la tabla en un desplegable, ver sus filas como en Excel, insertar filas nuevas con el icono o borrar registros.

3. Editar Pragmas

Configuración interna de SQLite. Aquí puedes asegurarte de que la casilla Foreign Keys esté activada.

4. Ejecutar SQL

Editor donde escribes sentencias SELECT, INSERT o CREATE TABLE y las ejecutas con el botón Play (F5).

¡Cuidado! El Error Más Común en DB Browser: "Guardar Cambios (Write Changes)"

Cuando agregas, editas o eliminas datos en DB Browser, los cambios quedan en una transacción abierta en memoria. Mientras no presiones el botón superior "Guardar cambios" (Write Changes / Ctrl+S):

  • Tu aplicación Java NO verá los datos nuevos que metiste en DB Browser.
  • Si tu aplicación Java intenta hacer un INSERT, UPDATE o DELETE mientras DB Browser tiene cambios sin guardar, SQLite lanzará el error [SQLITE_BUSY] The database file is locked.

Parte 2: Guía de XAMPP y phpMyAdmin (Servidor MySQL)

XAMPP es un paquete de desarrollo local que incluye el servidor web Apache y el motor de base de datos MySQL / MariaDB junto con su panel de administración web phpMyAdmin.

1. Encender los Servicios

Abre el XAMPP Control Panel y pulsa Start en dos módulos:
• Apache (necesario para abrir la interfaz web phpMyAdmin en el puerto 80).
• MySQL (inicia el servidor de base de datos en el puerto 3306). Ambos deben ponerse en color verde.

2. Crear informacion_db

Haz clic en el botón Admin de la fila MySQL (o entra a http://localhost/phpmyadmin en tu navegador). En la barra lateral izquierda haz clic en Nueva (New), escribe informacion_db y pulsa Crear. Luego ve a la pestaña SQL y pega el script de creación de tablas.

3. Monitorear Conexiones Activas

En la página principal de phpMyAdmin, ve a la pestaña superior Estado del servidor (Status) → Procesos (Processes). Ahí verás en tiempo real cada conexión TCP abierta por tu aplicación Java, el usuario (root), la BD (informacion_db) y el estado (Sleep / Query).

Práctica de Laboratorio: Verificando el Singleton en phpMyAdmin (EjemploMYSQL.java)

En el repositorio BaseDatos se incluye la clase EjemploMYSQL.java, diseñada específicamente para comprobar en XAMPP por qué el patrón Singleton es vital en bases de datos:

  1. El programa ejecuta un bucle for de 10 iteraciones pidiendo DatosMYSQL.getInstance().getConexion().
  2. Sin Singleton, se abrirían 10 conexiones simultáneas contra MySQL, agotando rápidamente el límite de conexiones del servidor (error Too many connections).
  3. Con Singleton, las 10 variables apuntan a la misma referencia en memoria, y al revisar Estado del servidor → Procesos en phpMyAdmin mientras el programa espera un ENTER en consola, comprobarás que solo existe 1 proceso activo.
