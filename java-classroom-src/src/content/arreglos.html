Arreglos (Arrays) y Memoria

La Muerte de malloc() y free()

En Java olvídate de pedir memoria manualmente. Los arreglos siempre se guardan de forma dinámica usando la palabra reservada new. ¿Y cómo evitas fugas de memoria sin free()? Java tiene un sistema llamado Recolector de Basura (Garbage Collector) que destruye automáticamente la memoria que ya no está en uso. ¡Una maravilla!

Sintaxis, .length y For-Each

A diferencia de C, donde un arreglo no sabe su propio tamaño, en Java todo arreglo tiene una propiedad mágica llamada .length. Además, te presentamos el bucle For-Each, que te permite recorrer todos los datos de golpe sin usar índices. 

public class arreglos {
    public static void main(String[] args){
        // Pedimos memoria en Heap para 3 enteros. 
        // ¡Nota!: Por defecto, Java los inicializa en 0 (no en basura)
        int[] datos = new int[3];
        
        datos[0] = 100;
        datos[1] = 200;
        datos[2] = 300;

        // 1. Recorrido Clásico usando .length
        System.out.println("--- Recorrido For Normal ---");
        for (int i=0; i < datos.length; i++){
            System.out.println("En indice " + i + " hay " + datos[i]);
        }

        // 2. El poderoso For-Each
        System.out.println("\n--- Recorrido For-Each ---");
        // Se lee: "Por cada variable entera 'dato' dentro de 'datos'..."
        for (int dato : datos){
            System.out.println("Valor impreso: " + dato);
        }
    }
}
