Scanner: La "Caja Negra"

Olvídate del scanf. En Java se utilizan Flujos de Datos (Streams) y clases para leer datos. Como aún no dominas la Programación Orientada a Objetos, el profesor te indica usar Scanner como una caja negra: solo apréndete la sintaxis exacta, pon los datos que te pide, y obtén la respuesta. Magia.

  • Regla 1: Importar arriba: import java.util.Scanner;
  • Regla 2: Instanciar: Scanner leer = new Scanner(System.in);
  • Regla 3: Extraer valores: leer.nextInt(), leer.next(), etc.
import java.util.Scanner; // Importación OBLIGATORIA

public class pasevalores {
    public static void main(String[] args){
        // CAJA NEGRA: Crear el scanner
        Scanner leer = new Scanner(System.in);
        
        // Evita bugs visuales en la terminal con los 'Enters'
        leer.useDelimiter("\n"); 

        System.out.print("Ingresa un numero entero: ");
        int dato = leer.nextInt(); // Lee entero de la consola
        System.out.println("Leiste: " + dato);
        
        System.out.print("Ingresa un texto continuo: ");
        String cadena = leer.next(); // Lee un string
        System.out.println("Leiste: " + cadena);
    }
}

Estructuras de Control (Repaso)

Si sabes C, ya sabes esto. if, for, while y do-while operan idéntico. La única mejora brutal es que en Java el switch sí permite evaluar Strings. 

public class Estructuracontrol {
    public static void main(String[] args){
        int edad = 17;
        if (edad >= 18) System.out.println("Mayor");
        else System.out.println("Menor");

        // Switch evaluando STRINGS (Imposible en C nativo)
        String mes = "Enero";
        switch(mes){
            case "Enero":
                System.out.println("Primer mes (1)");
                break;
            case "Febrero":
                System.out.println("Segundo mes (2)");
                break;
        }

        // Bucle For idéntico
        System.out.print("For: ");
        for (int i=0; i<5; i++) System.out.print(i + " ");
        
        System.out.print("\nWhile con Break: ");
        int cont = 0;
        while(true){
            if(cont > 3) break;
            System.out.print(cont + " ");
            cont++;
        }
    }
}

Funciones (Métodos)

Para hacer una función, simplemente métela en tu clase. Si vas a llamarla directamente desde tu main (que es static), tu función obligatoriamente debe ser static también. 

public class funciones {
    public static void main(String[] args){
        int resultado = suma(2, 3);
        System.out.println("Resultado: " + resultado);
    }

    // public: Todo el mundo la ve
    // static: Pertenece a la clase, se llama directo
    public static int suma(int a, int b){
        return a + b;
    }
}
