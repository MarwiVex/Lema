POO Avanzado: Herencia, Polimorfismo, Casteo y Estructuras en Memoria

Esta guía profundiza en los pilares fundamentales de la Programación Orientada a Objetos en Java. Analizaremos en detalle cómo funciona la herencia mediante extends, el mecanismo interno del polimorfismo y el casteo (Upcasting y Downcasting), el peligro del ocultamiento de variables (Shadowing), y la diferencia en memoria entre LinkedList y arreglos tradicionales.

1. Herencia en Java: La palabra clave extends

¿Qué hace exactamente extends?

La palabra clave extends establece una relación de Herencia entre dos clases, creando una jerarquía de tipo "Es Un" (Is-A). Por ejemplo: public class Televisor extends Electronico significa que un Televisor es un Electronico.

// Clase Padre (Superclase) public class Electronico {
protected String marca;
protected Float precio;
}
// Clase Hija (Subclase) public class Televisor extends Electronico {
// Hereda marca y precio automáticamente
private Float pulgadas; // Atributo exclusivo
}
Asignación en Memoria

Al hacer new Televisor(), Java reserva un bloque de memoria en el Heap que contiene los campos del padre (ns, marca, modelo, precio) MÁS los campos de la clase hija (pulgadas, tipo).

Modificador protected

Permite que los atributos de la superclase sean accesibles directamente por las clases hijas (y clases dentro del mismo paquete), pero manteniéndose protegidos contra accesos no autorizados desde paquetes externos.

Herencia Única

En Java NO existe herencia múltiple de clases. Una clase solo puede extender de una superclase. Esto previene la ambigüedad del "Problema del Diamante".

2. Polimorfismo, Casteo (Upcasting / Downcasting) e instanceof

El Polimorfismo permite tratar objetos de distintas subclases (Televisor, Videojuego) a través de un tipo genérico común (Electronico).

Upcasting (Conversión Implícita)

Es la conversión de una subclase a su superclase. Es 100% segura y automática.

Electronico e1 = new Televisor(); // Válido
LinkedList<Electronico> lista = new LinkedList<>();
lista.add(new Videojuego()); // Upcasting automático

Limitación: A través de la variable e1 (tipo Electronico), solo puedes invocar métodos definidos en Electronico. No puedes llamar a setPulgadas() directamente.

Downcasting (Conversión Explícita)

Es recuperar el tipo específico de la clase hija a partir de una referencia del padre. Requiere un casteo manual (TipoHijo).

Electronico e1 = lista.get(0);
Televisor t = (Televisor) e1; // Casteo explícito
t.setPulgadas(55f); // ¡Ahora sí es accesible!

Peligro: Si e1 en realidad fuera un Videojuego, la JVM lanzará un error fatal: ClassCastException.

Validación Segura con instanceof

Antes de realizar un Downcasting, se debe verificar si el objeto en memoria pertenece a la clase requerida usando el operador instanceof.

Forma Tradicional: 
if (electronico instanceof Televisor) {
    Televisor tele = (Televisor) electronico;
    tele.setPulgadas(55f);
}
Forma Moderna (Pattern Matching - Java 16+): 
// Castea y asigna la variable en un solo paso
if (electronico instanceof Televisor tele) {
    tele.setPulgadas(55f);
}

3. Ocultamiento de Variables (Shadowing) vs Sobrescritura

El Error de Redeclarar Atributos en las Clases Hijas

Analicemos el siguiente error detectado en la clase Videojuego de tu código original:

public class Electronico { protected Float Precio; }

public class Videojuego extends Electronico {
private Float Precio; // ✗ ¡ERROR DE DISEÑO! (Shadowing)
private Integer Capacidad;
}

• ¿Qué sucede físicamente? Java crea dos variables distintas en memoria para el mismo objeto: super.Precio (heredada del padre) y this.Precio (declarada en el hijo).

• ¿Por qué rompe el programa? Si ejecutas electronico.setPrecio(100f) desde una referencia de tipo Electronico, se modificará el Precio del padre. Pero los métodos propios de Videojuego accederán al Precio del hijo (que seguirá valiendo null).

• Regla de Oro: NUNCA vuelvas a declarar en una clase hija un atributo que ya heredaste del padre. Simplemente usa los campos del padre.

4. LinkedList vs Arreglos en Memoria y Rendimiento

Arreglos Tradicionales / ArrayList

  • • Memoria reservada en un bloque contiguo.
  • • Acceso por índice: Complejidad O(1) (inmediato por fórmula matemática de dirección offset).
  • • Inserción / Eliminación: Costosa O(N) porque requiere desplazar los demás elementos.

LinkedList (Lista Enlazada Doble)

  • • Elementos (Nodos) dispersos en la memoria Heap enlazados con punteros next y prev.
  • • Acceso por índice: Complejidad O(N). Para leer la posición 5, Java debe iterar desde el inicio (o final) pasando por los nodos 0 → 1 → 2 → 3 → 4 → 5.
  • • Inserción / Eliminación en los extremos: Muy veloz O(1) (solo se cambian los enlaces/punteros).

Antipatrón de Rendimiento Frecuente

En tu código inicial hacías esto:

Ineficiente (Múltiples recorridos O(N)): electronicos.get(0).setMarca("Samsung");
electronicos.get(0).setModelo("QLED");
electronicos.get(0).setNS("SN123");
Eficiente (Extracción única O(1)): Electronico e = electronicos.get(0);
e.setMarca("Samsung");
e.setModelo("QLED");
e.setNS("SN123");

5. Errores Sintácticos Frecuentes en Java

1. Literal Float en Java

Por defecto, números decimales como 32323.55 son interpretados por Java como double (64 bits). Para asignarlos a un Float (32 bits), es obligatorio incluir el sufijo f:
float precio = 32323.55f;

2. Especificadores de String.format

En tu código tenías String.format("%NS %s..."). El símbolo % indica el inicio de un especificador de formato. Escribir %NS genera un error. Debe ser NS: %s.

3. Convenciones Naming (camelCase)

En Java las variables y métodos usan camelCase (ej. marca, setPrecio()). Las clases usan PascalCase (ej. Televisor, Electronico).

6. Código Completo Corregido y Documentado

A continuación se presenta el código completo con la estructura modular corregida, aplicación de buenas prácticas, resolviendo el problema de Shadowing y usando Downcasting seguro con instanceof.

EjercicioCompleto.java 
import java.util.LinkedList;

// ==========================================
// 1. SUPERCLASE BASE (Electronico)
// ==========================================
class Electronico {
    // Atributos protected: Accesibles por la misma clase, paquete y clases hijas
    protected String ns;
    protected String marca;
    protected String modelo;
    protected Float precio;

    // Getters y Setters respetando convención camelCase
    public String getNs() { return ns; }
    public void setNs(String ns) { this.ns = ns; }

    public String getMarca() { return marca; }
    public void setMarca(String marca) { this.marca = marca; }

    public String getModelo() { return modelo; }
    public void setModelo(String modelo) { this.modelo = modelo; }

    public Float getPrecio() { return precio; }
    public void setPrecio(Float precio) { this.precio = precio; }

    // Sobrescritura de toString() heredado de java.lang.Object
    @Override
    public String toString() {
        return String.format("NS: %s | Marca: %s | Modelo: %s | Precio: $%.2f", 
                              ns, marca, modelo, precio != null ? precio : 0.0f);
    }
}

// ==========================================
// 2. SUBCLASE TELEVISOR (Hereda con extends)
// ==========================================
class Televisor extends Electronico {
    // Atributos EXCLUSIVOS de Televisor
    private Float pulgadas;
    private String tipo;

    public Float getPulgadas() { return pulgadas; }
    public void setPulgadas(Float pulgadas) { this.pulgadas = pulgadas; }

    public String getTipo() { return tipo; }
    public void setTipo(String tipo) { this.tipo = tipo; }

    // Reutilizamos la lógica del padre mediante super.toString()
    @Override
    public String toString() {
        return String.format("%s | Pulgadas: %.1f\" | Tipo: %s", 
                              super.toString(), 
                              pulgadas != null ? pulgadas : 0.0f, 
                              tipo != null ? tipo : "N/A");
    }
}

// ==========================================
// 3. SUBCLASE VIDEOJUEGO (Hereda con extends)
// ==========================================
class Videojuego extends Electronico {
    // Atributos EXCLUSIVOS de Videojuego
    private Integer capacidad;
    private String tipo; 
    // NOTA IMPORTANTE: Se eliminó 'private Float precio;' para EVITAR SHADOWING (ocultamiento de variables)

    public Integer getCapacidad() { return capacidad; }
    public void setCapacidad(Integer capacidad) { this.capacidad = capacidad; }

    public String getTipo() { return tipo; }
    public void setTipo(String tipo) { this.tipo = tipo; }

    @Override
    public String toString() {
        return String.format("%s | Capacidad: %d GB | Tipo: %s", 
                              super.toString(), 
                              capacidad != null ? capacidad : 0, 
                              tipo != null ? tipo : "N/A");
    }
}

// ==========================================
// 4. CLASE PRINCIPAL (Main)
// ==========================================
public class Main {
    public static void main(String[] args) {
        // Creación de lista polimórfica (guarda referencias de tipo Electronico)
        LinkedList electronicos = new LinkedList<>();

        // Upcasting implícito: Televisor y Videojuego son añadidos como Electronico
        electronicos.add(new Televisor());
        electronicos.add(new Videojuego());

        // Optimización: Extraemos la referencia del primer elemento para evitar múltiples .get(0) O(N)
        Electronico primerElem = electronicos.get(0);
        primerElem.setMarca("Samsung");
        primerElem.setModelo("QLED 4K");
        primerElem.setNs("SN-998877");
        primerElem.setPrecio(32323.55f); // Sufijo 'f' obligatorio para Float

        // DOWNCASTING SEGURO usando instanceof (Pattern Matching de Java 16+)
        if (primerElem instanceof Televisor tele) {
            tele.setPulgadas(55f);
            tele.setTipo("Smart TV");
        }

        // Configuración del segundo elemento (Videojuego)
        Electronico segundoElem = electronicos.get(1);
        segundoElem.setMarca("Sony");
        segundoElem.setModelo("PlayStation 5");
        segundoElem.setNs("PS5-100200");
        segundoElem.setPrecio(14999.99f);

        if (segundoElem instanceof Videojuego juego) {
            juego.setCapacidad(1024); // 1 TB
            juego.setTipo("Consola de Sobremesa");
        }

        System.out.println("Total de elementos iniciales: " + electronicos.size());
        System.out.println("\n--- LISTA DE DISPOSITIVOS ---");
        for (Electronico e : electronicos) {
            System.out.println(e); // Invoca automáticamente el toString() polimórfico
        }

        // Eliminación del primer elemento
        electronicos.remove();

        System.out.println("\nTotal tras remover el primero: " + electronicos.size());
        System.out.println("--- ELEMENTOS RESTANTES ---");
        for (Electronico e : electronicos) {
            System.out.println(e);
        }
    }
}
