Reto 2: Rompiendo la Copia Fantasma

Objetivo: Entender el caos y curarlo.
1. Crea int[][] matriz = {{10,20}, {30,40}};
2. Haz una copia mala: int[][] mala = matriz.clone();
3. Modifica mala[0][0] = 99; y luego imprime matriz[0][0]. Verás que se rompió la original.
4. Elimina la copia mala e implementa tú mismo la Copia Profunda con doble ciclo for. Demuestra que modificar la copia ya no afecta el original.

int[][] copiaFinal = new int[matriz.length][];
for(int i=0; i < matriz.length; i++){
  copiaFinal[i] = new int[matriz[i].length]; // Aísla la fila
  for(int j=0; j < matriz[i].length; j++){
    copiaFinal[i][j] = matriz[i][j]; // Copia el valor
  }
}
