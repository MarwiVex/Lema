Diagramas UML, Herencia y Editor Interactivo

Los diagramas de clases UML (Unified Modeling Language) son una representación visual del diseño orientado a objetos de un sistema. Nos permiten planificar la estructura de clases, sus atributos, métodos y las relaciones entre ellas antes o durante la programación.

Explicación de la Herencia y este Diagrama

Superclase (Clase Padre): Electronico

Es la clase general que engloba los atributos y comportamientos comunes a todos los dispositivos electrónicos (NS, SKU, Marca, Modelo, Precio y sus respectivos Getters/Setters).

Evita la duplicación de código compartiendo estas propiedades con sus clases hijas.

Subclases (Clases Hijas): Television, Estereo, Consola

Heredan automáticamente todos los atributos y métodos de Electronico usando la palabra clave extends en Java, e introducen sus propios atributos específicos (ej. Pulgadas en Television, Potencia en Estereo, Capacidad en Consola).

Sintaxis PlantUML: Electronico <|-- Television representa la flecha de herencia (generalización).

Simbología de Visibilidad en UML

- Privado (private): Accesible solo dentro de la misma clase.
+ Público (public): Accesible desde cualquier lugar del programa.
# Protegido (protected): Accesible en el paquete y por subclases.

Compilador y Editor UML en Vivo

Edita la sintaxis PlantUML en el panel izquierdo. El diagrama se renderizará automáticamente en tiempo real en el visualizador interactivo.

Código Java Equivalente de este Diagrama

Así se traduce la jerarquía del diagrama UML a código Java real compilable:

JerarquiaElectronicos.java 
// Superclase
class Electronico {
    private String NS;
    private String SKU;
    private String Marca;
    private String Modelo;
    private float Precio;

    public void setNS(String NS) { this.NS = NS; }
    public String getNS() { return this.NS; }
    public void setMarca(String Marca) { this.Marca = Marca; }
    public String getMarca() { return this.Marca; }
    public void setModelo(String Modelo) { this.Modelo = Modelo; }
    public String getModelo() { return this.Modelo; }
    public void setSKU(String SKU) { this.SKU = SKU; }
    public String getSKU() { return this.SKU; }
    public void setPrecio(float Precio) { this.Precio = Precio; }
    public float getPrecio() { return this.Precio; }
}

// Subclase 1: Television (Hereda de Electronico)
class Television extends Electronico {
    private float Pulgadas;
    private String Tipo;

    public void setPulgadas(float Pulgadas) { this.Pulgadas = Pulgadas; }
    public float getPulgadas() { return this.Pulgadas; }
    public void setTipo(String Tipo) { this.Tipo = Tipo; }
    public String getTipo() { return this.Tipo; }
}

// Subclase 2: Estereo (Hereda de Electronico)
class Estereo extends Electronico {
    private int Potencia;

    public void setPotencia(int Potencia) { this.Potencia = Potencia; }
    public int getPotencia() { return this.Potencia; }
}

// Subclase 3: Consola (Hereda de Electronico)
class Consola extends Electronico {
    private String Tipo;
    private int Capacidad;

    public void setTipo(String Tipo) { this.Tipo = Tipo; }
    public String getTipo() { return this.Tipo; }
    public void setCapacidad(int Capacidad) { this.Capacidad = Capacidad; }
    public int getCapacidad() { return this.Capacidad; }
}

public class Main {
    public static void main(String[] args) {
        Television tv = new Television();
        tv.setMarca("Samsung");
        tv.setModelo("Neo QLED");
        tv.setPulgadas(65.0f);
        tv.setPrecio(1200.50f);

        System.out.println("TV Marca: " + tv.getMarca() + " | Modelo: " + tv.getModelo() + " | Pulgadas: " + tv.getPulgadas());
    }
}
