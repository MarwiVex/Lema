20. Generación de Reportes y PDF con JasperReports

En sistemas empresariales y proyectos escolares completos, mostrar datos en un TableView no es suficiente: el usuario necesita imprimir facturas, inventarios o exportar reportes en PDF. Para ello, el ecosistema Java utiliza JasperReports Library junto con su diseñador visual Jaspersoft Studio, tal como se implementa en el paquete EjemploJasper del proyecto BaseDatos.

1. El Flujo de Trabajo en 4 Pasos (De .jrxml al Visor / PDF)

PASO 1: Diseño XML

ReporteCafe.jrxml

Se diseña visualmente arrastrando textos, líneas y campos en Jaspersoft Studio (similar a Scene Builder pero para documentos).

PASO 2: Compilación

ReporteCafe.jasper

En Jaspersoft Studio pulsas el icono Compile Report (martillo) para generar el archivo binario .jasper que colocas en la raíz de tu proyecto Java.

PASO 3: Llenado (Fill)

JasperFillManager

Java toma el archivo .jasper y le inyecta tu LinkedList<Cafe> envuelta en un JRBeanCollectionDataSource, produciendo un JasperPrint.

PASO 4: Salida

JasperViewer / PDF

Se abre la ventana interactiva JasperViewer (desde donde el usuario puede imprimir o guardar en PDF, Excel, DOCX) o se exporta directo a PDF.

2. Configuración en pom.xml y module-info.java

En la versión 7.0.8 de JasperReports utilizada en el proyecto, se agregan los artefactos jasperreports y jasperreports-pdf. Además, como JasperViewer está construido sobre Swing/AWT y lee los POJOs por reflexión, el archivo module-info.java requiere permisos específicos:

pom.xml (Dependencias JasperReports 7.0.8) 
<!-- JasperReports 7.0.8 -->
<dependency>
    <groupId>net.sf.jasperreports</groupId>
    <artifactId>jasperreports</artifactId>
    <version>7.0.8</version>
</dependency>
<dependency>
    <groupId>net.sf.jasperreports</groupId>
    <artifactId>jasperreports-pdf</artifactId>
    <version>7.0.8</version>
</dependency>
module-info.java (Requerimientos de Jasper) 
module com.example.basedatos {
    requires javafx.controls;
    requires javafx.fxml;
    requires java.sql;
    requires java.desktop; // Requerido por JasperViewer (Swing)
    requires net.sf.jasperreports.core; // Motor de JasperReports

    // OBLIGATORIO: abrir el paquete POJO para que JRBeanCollectionDataSource
    // pueda invocar getIdcafe(), getProductor() y getCantidad() por reflexión
    opens com.example.basedatos.POJO;
    exports com.example.basedatos.POJO;
    exports EjemploJasper;
}

3. Anatomía de la Plantilla ReporteCafe.jrxml

Un reporte en Jaspersoft Studio se divide en Bandas (Bands) horizontales y utiliza dos tipos de expresiones dinámicas:

Parámetros: $P{nombre} y Campos: $F{atributo}

  • Parámetros (<parameter name="anio"/> → $P{anio}): Valores únicos para todo el reporte (ej. título, fecha, nombre del usuario que imprimió).
  • Campos (<field name="idcafe"/> → $F{idcafe}): Deben llamarse exactamente igual que la propiedad JavaBean de tu clase Cafe.java (como el getter es getIdcafe(), el field debe llamarse idcafe).

Bandas Principales del Documento

  • <title>: Aparece una sola vez al principio del reporte (ej. "Cafe reportes " + $P{anio}).
  • <columnHeader>: Cabecera de la tabla con textos estáticos (ID Café, Productor, Cantidad).
  • <detail>: ¡Se repite automáticamente una vez por cada objeto Cafe de tu LinkedList!
ReporteCafe.jrxml (Plantilla real del proyecto BaseDatos) 
<!-- Created with Jaspersoft Studio version 7.0.8.final -->
<jasperReport name="ReporteCafe" language="java" pageWidth="595" pageHeight="842" columnWidth="555" leftMargin="20" rightMargin="20" topMargin="20" bottomMargin="20">
    <!-- 1. Parámetro global con valor por defecto "2026" -->
    <parameter name="anio" class="java.lang.String">
        <defaultValueExpression><![CDATA["2026"]]></defaultValueExpression>
    </parameter>

    <!-- 2. Campos enlazados a los getters de Cafe.java (getIdcafe, getProductor, getCantidad) -->
    <field name="idcafe" class="java.lang.Integer"/>
    <field name="productor" class="java.lang.String"/>
    <field name="cantidad" class="java.lang.Float"/>

    <!-- 3. Banda de Título -->
    <title height="50">
        <element kind="textField" x="0" y="10" width="555" height="30" fontSize="18.0" bold="true" hTextAlign="Center" vTextAlign="Middle">
            <expression><![CDATA["Cafe reportes  " + $P{anio}]]></expression>
        </element>
    </title>

    <!-- 4. Banda de Encabezados de Columna -->
    <columnHeader height="25">
        <element kind="staticText" x="0" y="0" width="100" height="25" bold="true" hTextAlign="Center">
            <text><![CDATA[ID Café]]></text>
        </element>
        <element kind="staticText" x="100" y="0" width="300" height="25" bold="true" hTextAlign="Left">
            <text><![CDATA[Productor]]></text>
        </element>
        <element kind="staticText" x="400" y="0" width="155" height="25" bold="true" hTextAlign="Right">
            <text><![CDATA[Cantidad]]></text>
        </element>
    </columnHeader>

    <!-- 5. Banda de Detalle (Se repite por cada elemento de la LinkedList) -->
    <detail>
        <band height="20">
            <element kind="textField" x="0" y="0" width="100" height="20" hTextAlign="Center">
                <expression><![CDATA[$F{idcafe}]]></expression>
            </element>
            <element kind="textField" x="100" y="0" width="300" height="20" hTextAlign="Left">
                <expression><![CDATA[$F{productor}]]></expression>
            </element>
            <element kind="textField" x="400" y="0" width="155" height="20" pattern="#,##0.00" hTextAlign="Right">
                <expression><![CDATA[$F{cantidad}]]></expression>
            </element>
        </band>
    </detail>
</jasperReport>

4. Ejecución en Java: EjemploJasper.java

Observa cómo en menos de 20 líneas de código consultamos la base de datos mediante AdmonCafe, transformamos la LinkedList<Cafe> en un JRBeanCollectionDataSource, rellenamos el reporte compilado ReporteCafe.jasper y lanzamos el visor:

EjemploJasper/EjemploJasper.java 
package EjemploJasper;

import com.example.basedatos.ADMON.AdmonCafe;
import com.example.basedatos.POJO.Cafe;
import net.sf.jasperreports.engine.JasperFillManager;
import net.sf.jasperreports.engine.JasperPrint;
import net.sf.jasperreports.engine.data.JRBeanCollectionDataSource;
import net.sf.jasperreports.view.JasperViewer;

import java.util.HashMap;
import java.util.LinkedList;
import java.util.Map;

public class EjemploJasper {
    public static void main(String[] args) {
        try {
            // 1. Obtener la lista de objetos desde la Base de Datos (MySQL o SQLite)
            AdmonCafe admon = new AdmonCafe();
            LinkedList cafes = admon.obtenerCafe();

            for (Cafe cafe : cafes) {
                System.out.println(cafe);
            }

            // 2. Envolver la LinkedList en un DataSource de JavaBeans para Jasper
            JRBeanCollectionDataSource datos = new JRBeanCollectionDataSource(cafes);

            // (Opcional) Mapa de parámetros para enviar valores a $P{anio}
            Map parametros = new HashMap<>();
            parametros.put("anio", "2026 - Cosecha Especial");

            // 3. Llenar el reporte compilado (.jasper) con los parámetros (o null) y la colección
            JasperPrint reporte = JasperFillManager.fillReport("ReporteCafe.jasper", parametros, datos);

            // 4. Mostrar el visor interactivo.
            // IMPORTANTE: el segundo parámetro "false" (isExitOnClose) evita que al cerrar
            // la ventana del reporte se cierre toda tu aplicación JavaFX con System.exit(0).
            JasperViewer vista = new JasperViewer(reporte, false);
            vista.setVisible(true);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

Tip: ¿Por qué pasar false en new JasperViewer(reporte, false)?

Si usas el constructor de un solo argumento new JasperViewer(reporte), cuando el usuario cierre la ventana del visor de PDF con la "X", JasperViewer ejecutará internamente System.exit(0) y matará toda tu ventana principal de JavaFX. Al pasar false como segundo argumento (isExitOnClose = false), solo se cierra la ventana del reporte y tu aplicación continúa activa.
