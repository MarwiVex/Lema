Matrices y Copias

Llegamos al tema donde la mayoría tropieza. En Java, NO EXISTEN las matrices de verdad. Es decir, no reserva un cuadro perfecto en memoria. Lo que hace Java es crear "Arreglos que apuntan a otros arreglos" (Jagged Arrays o Arreglos Escalonados).

Construyendo una Matriz

Instancias un arreglo "maestro" (las filas). Luego, a cada espacio de ese arreglo le insertas otro arreglo (las columnas). Esto permite que cada fila pueda tener un tamaño diferente. 

public class matriz {
    public static void main(String[] args){
        // Arreglo maestro de 3 filas. Columnas vacías.
        int[][] datos = new int[3][];
        
        // Instanciamos manualmente las columnas de CADA fila.
        datos[0] = new int[2];
        datos[1] = new int[2];
        datos[2] = new int[2];

        int cont = 1;
        // Llenado con for anidado usando .length
        for (int i=0; i < datos.length; i++){
            for (int j=0; j < datos[i].length; j++){
                datos[i][j] = cont++;
            }
        }

        // Impresión usando doble for-each
        for (int[] fila : datos){          // Extrae arreglos (filas)
            for(int dato : fila){          // Extrae enteros de cada fila
                System.out.print(dato + "\t");
            }
            System.out.println();
        }
    }
}

El Peligro: La Copia Fantasma (Shallow Copy)

Si tienes un arreglo de 1 dimensión y usas el método .clone(), hace una copia perfecta. Pero si tienes una matriz, ¡es una trampa mortal!

Al hacer matriz.clone(), Java copia la estructura principal (las filas), pero NO duplica la memoria de las columnas internas. Ambas matrices (original y copia) terminan compartiendo las mismas columnas en la RAM. Si alteras la copia, la original se muta mágicamente y tus datos colapsan.

Solución: La Copia Profunda (Deep Copy)

Para crear una copia verdaderamente independiente y aislada de todo, tienes que decirle a Java que asigne memoria nueva a cada fila y luego copiar los números uno por uno manualmente con un for. 

public class copiaprofunda {
    public static void main(String[] args){
        int[][] original = {{1, 2}, {3, 4}};
        
        // --- COPIA PROFUNDA A MANO ---
        // 1. Instanciamos el cascarón principal (Filas)
        int[][] copiaLimpia = new int[original.length][]; 
        
        for (int i = 0; i < original.length; i++) {
            // 2. Pedimos MEMORIA NUEVA para aislar la fila
            copiaLimpia[i] = new int[original[i].length];
            
            // 3. Copiamos el número celda a celda
            for (int j = 0; j < original[i].length; j++) {
                copiaLimpia[i][j] = original[i][j];
            }
        }
        
        // ¡PRUEBA DE AISLAMIENTO!
        copiaLimpia[0][0] = 999;
        System.out.println("En Original hay: " + original[0][0]); // Imprime 1
        System.out.println("En Copia Limpia hay: " + copiaLimpia[0][0]); // Imprime 999
    }
}
