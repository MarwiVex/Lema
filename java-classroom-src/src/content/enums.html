Tipos Enumerados (Enums)

En ocasiones, una variable solo debería poder tomar un conjunto específico de valores predefinidos. Por ejemplo, los días de la semana, los meses del año, o el estado de un producto (Activo o Descontinuado). Para evitar errores usando cadenas de texto libres (Strings), Java provee los Enumerators (Enums).

1. Definiendo un Enum

Un enum es un tipo de clase especial que representa un grupo de constantes invariables. Se declaran usando la palabra reservada enum en lugar de class. Por convención, las constantes se escriben en MAYÚSCULAS.

ESTADO.java 
public enum ESTADO {
    ACTIVO, DESCONTINUADO
}

2. Aplicando Enums en Clases

Podemos usar el Enum como si fuera cualquier otro tipo de dato en nuestras clases, asegurando de esta forma que nadie pueda asignar un valor que no sea ACTIVO o DESCONTINUADO.

Producto.java 
public class Producto {
    private String SKU;
    // La variable de estado usa el tipo de dato ESTADO (el Enum)
    private ESTADO estado;
    
    public Producto(String SKU, ESTADO estado) {
        this.SKU = SKU;
        this.estado = estado;
    }
    
    public void imprimirEstado() {
        // Uso simple en condicionales
        if (this.estado == ESTADO.ACTIVO) {
            System.out.println("El producto se puede vender.");
        } else {
            System.out.println("El producto ya no se vende.");
        }
    }
}

3. Conversión desde Archivos de Texto

ESTADO.valueOf(String)

Cuando leemos datos de un archivo de texto, obtenemos un String puro (por ejemplo, "ACTIVO"). Para convertir ese texto de vuelta a un objeto Enum, utilizamos el método estático valueOf(), el cual ya viene incluido automáticamente por Java en todos los enums.

// Supongamos que leemos una línea del archivo
String linea = "JUGUETE|SKU123|ACTIVO|Pelota";
String[] datos = linea.split("\\|");

// Extraemos el texto "ACTIVO" en datos[2] y lo convertimos a Enum
ESTADO estadoProducto = ESTADO.valueOf(datos[2]);

// Ahora ya podemos crear nuestro objeto seguro
Producto p = new Producto(datos[1], estadoProducto);

Cuidado: Si el string no coincide exactamente con el nombre del enum (por ejemplo, "Activo" o " ACTIVO " con espacios), valueOf lanzará una excepción IllegalArgumentException.
