Interfaces, Comparable y Comparator

Las interfaces son una de las herramientas más potentes en Java para lograr abstracción y polimorfismo puro. Además, aprenderemos a utilizar las interfaces nativas de Java Comparable y Comparator para dotar a nuestros objetos de la capacidad de ordenarse automáticamente.

1. ¿Qué es una Interfaz?

Una interfaz es como un contrato estricto. Define qué debe hacer una clase (los nombres de los métodos), pero no cómo lo hace (sin cuerpo de método). Si una clase dice que implementa una interfaz, está obligada a proveer el código para todos los métodos definidos en ella.

// Definición de la interfaz public interface Imprimible {
void imprimirTicket(); // Método sin cuerpo (abstracto por defecto)
}

// Implementación en una clase public class Producto implements Imprimible {
@Override
public void imprimirTicket() {
System.out.println("Imprimiendo ticket del producto...");
}
}

2. Ordenamiento Natural: Comparable<T>

La interfaz Comparable se implementa en la misma clase del objeto que queremos ordenar. Define cuál es el criterio de ordenamiento por defecto (natural) de esa clase. Solo nos obliga a implementar un método: compareTo(T o).

Producto.java 
public abstract class Producto implements Comparable {
    protected String SKU;
    
    public String getSKU() { return SKU; }

    @Override
    public int compareTo(Producto otroProducto) {
        // Orden natural: por el atributo String SKU alfabéticamente
        return this.SKU.compareTo(otroProducto.getSKU());
        
        // Si fuera un número entero (ej: id):
        // return Integer.compare(this.id, otroProducto.getId());
    }
}

Al hacer esto, puedes llamar a listaProductos.sort(null) y Java ordenará automáticamente los productos por SKU.

3. Múltiples Criterios: Comparator<T>

¿Qué pasa si queremos ordenar a veces por SKU, a veces por Nombre, y a veces por Tipo? Como Comparable solo permite un orden natural, usamos Comparator para definir criterios de ordenamiento externos y múltiples.

ComparadorPorNombre.java 
import java.util.Comparator;

public class ComparadorPorNombre implements Comparator {
    @Override
    public int compare(Producto p1, Producto p2) {
        // Asumiendo que existe un getTitulo() o getNombre() 
        // dependiendo de la estructura
        return p1.getNombre().compareTo(p2.getNombre());
    }
}
ComparadorPorTipoYSKU.java 
import java.util.Comparator;

public class ComparadorPorTipoYSKU implements Comparator {
    @Override
    public int compare(Producto p1, Producto p2) {
        // 1. Primero comparamos por la clase (Juguete vs Pelicula)
        int tipoComparacion = p1.getClass().getSimpleName()
                                .compareTo(p2.getClass().getSimpleName());
        
        // 2. Si son del mismo tipo (empate == 0), comparamos por SKU
        if (tipoComparacion == 0) {
            return p1.getSKU().compareTo(p2.getSKU());
        }
        
        return tipoComparacion;
    }
}

Aplicando el Ordenamiento a una Lista

Una vez implementados el Comparable y los Comparators, podemos pasarlos al método sort() de nuestra colección.

LinkedList<Producto> inventario = new LinkedList<>();

// Usando Comparable (Orden Natural por SKU)
inventario.sort(null);

// Usando Comparator por Nombre
inventario.sort(new ComparadorPorNombre());

// Usando Comparator Combinado (Tipo + SKU)
inventario.sort(new ComparadorPorTipoYSKU());
