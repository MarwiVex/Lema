21. JasperReports con Base de Datos: Data Adapter, Dataset SQL e Integración en IntelliJ

En la sección anterior alimentamos el reporte enviando una LinkedList<Cafe> desde Java (JRBeanCollectionDataSource), pero eso tenía una limitación importante: el objeto Cafe solo guardaba el número variedadCafe (ID foráneo) y no el nombre de la variedad. En esta sección veremos el flujo completo de JasperReports conectado directamente a una Base de Datos mediante SQL tal como se implementó en el repositorio MarwiVex/baseDatos: descargar el .jar de Maven, crear el Data Adapter en Jaspersoft Studio, configurar el Dataset and Query con clic derecho usando INNER JOIN, pasar los parámetros y la conexión desde IntelliJ IDEA, y lanzar el reporte desde un botón en JavaFX.

ENFOQUE 1 (Sección 20): Colección de Objetos

JRBeanCollectionDataSource(cafes)

  • El archivo .jrxml no tiene consulta SQL.
  • Los campos $F{...} leen los getters de Cafe.java por reflexión.
  • Tercer parámetro de fillReport: el objeto JRBeanCollectionDataSource.
ENFOQUE 2 (Sección 21): Conexión Directa a BD + SQL

datos.getConexion() + <query language="SQL">

  • El reporte guarda adentro su propia consulta SQL con INNER JOIN.
  • Permite cruzar tablas (Cafe + VariedadCafe) para mostrar el nombre de la variedad.
  • Tercer parámetro de fillReport: el objeto Connection (datos.getConexion()).

1. Obtener el Driver .jar de Maven para Jaspersoft Studio

Aunque IntelliJ descarga automáticamente los drivers JDBC gracias al pom.xml, Jaspersoft Studio es un programa independiente y no lee tu pom.xml. Para que Jaspersoft Studio pueda abrir tu archivo informacion.db (SQLite) o conectarse a MySQL mientras diseñas el reporte, necesitas indicarle la ruta del archivo .jar del conector JDBC. Tienes 3 formas de obtenerlo:

Opción A: Descargar de Maven Repository

  1. Entra a mvnrepository.com y busca sqlite-jdbc (grupo org.xerial, versión 3.47.0.0) o mysql-connector-j (versión 8.4.0).
  2. Entra a la versión y en la fila Files haz clic en el botón jar para descargar sqlite-jdbc-3.47.0.0.jar.
  3. Guárdalo en una carpeta accesible (por ejemplo, en Documentos o en la carpeta de tu proyecto).

Opción B: Usar la Carpeta Local .m2 de Maven

Como IntelliJ ya descargó las dependencias del pom.xml, el archivo .jar ya está en tu disco duro dentro de la caché oculta .m2 de tu usuario:

C:\Users\TuUsuario\.m2\repository\org\xerial\sqlite-jdbc\3.47.0.0\sqlite-jdbc-3.47.0.0.jar

Opción C: Comando Maven en Terminal

Si abres la terminal integrada de IntelliJ IDEA (Alt + F12) y ejecutas este comando, Maven copiará todos los .jar de tu proyecto en target/dependency/:

mvn dependency:copy-dependencies

2. Crear el Data Adapter (informacionCafe) en Jaspersoft Studio

Un Data Adapter le enseña a Jaspersoft Studio cómo conectarse a tu base de datos para validar tu consulta SQL y extraer las columnas automáticamente. Sigue estos pasos exactos:

  1. Abrir el Repository Explorer: En Jaspersoft Studio, ubica el panel Repository Explorer (normalmente a la izquierda). Si no lo ves, ve al menú superior Window → Show View → Other... → Jaspersoft Studio → Repository Explorer.
  2. Clic derecho en Data Adapters: Dentro de Repository Explorer, haz clic derecho sobre el icono Data Adapters → selecciona Create Data Adapter.
  3. Elegir tipo JDBC: En la lista elige Database JDBC Connection y haz clic en Next.
  4. ¡PRIMERO! Pestaña Inferior "Driver Classpath" (Agregar el .jar):
    En la parte inferior de la ventana verás dos pestañas: Database Location y Driver Classpath. Entra a Driver Classpath, haz clic en el botón Add y selecciona el archivo sqlite-jdbc-3.47.0.0.jar (o mysql-connector-j-8.4.0.jar) que descargaste en el Paso 1.
    Nota: Si olvidas este paso, al probar la conexión te dará el error java.lang.ClassNotFoundException: org.sqlite.JDBC.
  5. Pestaña Superior "Database Location" (Driver y Ruta / URL): Regresa a la pestaña Database Location y llena los datos exactamente así:
    Configuración para SQLite (informacion.db)
    • Name: informacionCafe
    • JDBC Driver: org.sqlite.JDBC (escríbelo manualmente si no sale en la lista)
    • JDBC Url: jdbc:sqlite:C:/Users/TuUsuario/.../baseDatos/informacion.db
    • Username / Password: (Dejar completamente en blanco)

    En Jaspersoft Studio sí debes poner la ruta absoluta completa hacia el archivo informacion.db de tu proyecto después de jdbc:sqlite:.

    Alternativa para MySQL / XAMPP (informacion_db)
    • Name: informacionCafe
    • JDBC Driver: com.mysql.cj.jdbc.Driver
    • JDBC Url: jdbc:mysql://localhost:3306/informacion_db
    • Username: root | Password: (vacío)

    Requiere tener encendido el módulo MySQL en el panel de control de XAMPP y agregar mysql-connector-j-8.4.0.jar en Driver Classpath.

  6. Probar y Guardar: Haz clic en el botón Test (arriba a la derecha). Debe aparecer una ventana emergente diciendo "Successful".Finalmente pulsa Finish.

3. Clic Derecho → Dataset and Query... y Comando SQL con INNER JOIN

Una vez creado el adaptador informacionCafe, hay que vincularlo a nuestro reporte y escribir la consulta SQL que extrae los cafés junto con el nombre de su variedad:

¿Dónde hacer Clic Derecho para abrir Dataset and Query?

  1. Abre tu archivo ReporteCafe.jrxml en Jaspersoft Studio.
  2. Ve al panel Outline (esquina inferior izquierda, donde están Styles, Parameters, Fields, Variables, Title, Detail...).
  3. Haz clic derecho sobre el primer elemento raíz (ReporteCafe) y selecciona Dataset and Query... en el menú contextual.
  4. Atajo alternativo: También puedes hacer clic derecho directamente sobre una zona vacía del diseño del reporte → Dataset and Query... (o pulsar el icono de cilindro con una tabla en la esquina superior derecha del área de diseño).

Configurar el Diálogo y Leer los Campos (Read Fields)

  1. En la esquina superior izquierda de la ventana Dataset and Query Dialog, despliega la lista de Data Adapter y selecciona tu adaptador informacionCafe.
  2. Asegúrate de que en Language esté seleccionado SQL (en el panel izquierdo verás tus tablas Cafe y VariedadCafe).
  3. Pega el comando SQL con INNER JOIN en el cuadro de texto central.
  4. Haz clic en el botón Read Fields (arriba a la derecha). Verás cómo en la pestaña inferior Fields aparecen automáticamente idcafe, productor, variedad y cantidad.
  5. (Opcional) Entra a la pestaña inferior Data Preview y pulsa Refresh Preview Data para verificar que devuelve los registros reales. Pulsa OK.
Comando SQL en "Dataset and Query" (Une Cafe y VariedadCafe) 
SELECT C.IDCafe, C.Productor, VC.Descripcion AS Variedad, C.Cantidad
FROM Cafe C INNER JOIN VariedadCafe VC
ON C.VariedadCafe=VC.IDVariedad

Arrastrar $F{variedad} y Compilar a ReporteCafeSQL.jasper

De vuelta en el diseño visual, abre el nodo Fields en el panel Outline y arrastra el nuevo campo variedad hacia la banda Detail (entre Productor y Cantidad). Jaspersoft creará automáticamente el encabezado estático Variedad en la banda Column Header y la expresión $F{variedad} en Detail.

Finalmente, haz clic en el icono del Martillo (Compile Report) en la barra superior de herramientas (o clic derecho sobre el reporte en el explorador → Compile Report). Esto generará el archivo compilado ReporteCafeSQL.jasper (y/o actualizará ReporteCafe.jasper), el cual debes copiar a la carpeta raíz de tu proyecto en IntelliJ IDEA (al mismo nivel que pom.xml e informacion.db).

4. Todo dentro de IntelliJ IDEA: Parámetros, Conexión y AdmonReporte

Ahora veamos exactamente qué se pasa como parámetro en JasperFillManager.fillReport(...) dentro de IntelliJ IDEA. El método recibe 3 argumentos:

ARGUMENTO 1: sourceFileName

"ReporteCafeSQL.jasper"

Ruta relativa al archivo binario .jasper ubicado en la raíz del proyecto IntelliJ.

ARGUMENTO 2: params (Map<String, Object>)

parametros o null

Un HashMap donde la clave coincide con el nombre del parámetro en Jaspersoft (ej. parametros.put("anio", "2067") para $P{anio}). Si pasas null, Jasper usa el defaultValueExpression ("2026").

ARGUMENTO 3: connection (java.sql.Connection)

datos.getConexion()

¡El cambio clave! En vez de pasar una lista, le pasamos la conexión JDBC del Singleton. Jasper ejecuta internamente el SELECT ... INNER JOIN sobre esa conexión.

A Prueba Directa y Exportación a PDF en EjemploJasper.java

Observa cómo en EjemploJasper.java se comentaron las líneas antiguas de JRBeanCollectionDataSource, se creó el mapa parametros pasando "anio" → "2067", se pasó conexion a fillReport y además se usó JasperExportManager.exportReportToPdfFile(reporte, "ReporteCafe.pdf") para generar el PDF directo en la raíz del proyecto:

src/main/java/EjemploJasper/EjemploJasper.java 
package EjemploJasper;

import com.example.basedatos.ADMON.AdmonCafe;
import com.example.basedatos.ADMON.Datos;
import com.example.basedatos.POJO.Cafe;
import net.sf.jasperreports.engine.JasperExportManager;
import net.sf.jasperreports.engine.JasperFillManager;
import net.sf.jasperreports.engine.JasperPrint;
import net.sf.jasperreports.engine.data.JRBeanCollectionDataSource;
import net.sf.jasperreports.view.JasperViewer;

import java.sql.Connection;
import java.util.HashMap;
import java.util.LinkedList;
import java.util.Map;

public class EjemploJasper {
    public static void main(String[] args){
        try {
            AdmonCafe admon = new AdmonCafe();
            LinkedList<Cafe> cafes = admon.obtenerCafe();

            for(Cafe cafe : cafes){
                System.out.println(cafe);
            }

            // 1. Mapa de parámetros: la clave "anio" inyecta el valor en $P{anio} del reporte
            Map<String, Object> parametros = new HashMap<>();
            parametros.put("anio", "2067");

            //JRBeanCollectionDataSource datos = new JRBeanCollectionDataSource(cafes);
            // 2. Obtenemos la conexión activa a la BD desde nuestro Singleton Datos
            Connection conexion = Datos.getInstance().getConexion();

            //JasperPrint reporte = JasperFillManager.fillReport("ReporteCafe.jasper", parametros, datos);
            // 3. Pasamos (archivo .jasper, mapa de parámetros, objeto Connection)
            JasperPrint reporte = JasperFillManager.fillReport("ReporteCafe.jasper", parametros, conexion);

            // 4. Exporta automáticamente el reporte lleno a un archivo PDF físico
            JasperExportManager.exportReportToPdfFile(reporte, "ReporteCafe.pdf");

            // 5. Muestra la ventana de vista previa sin matar la app al cerrar (false)
            JasperViewer vista = new JasperViewer(reporte, false);
            vista.setVisible(true);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

B Arquitectura Limpia: Clase AdmonReporte.java en el Paquete ADMON

Para integrar los reportes dentro de la aplicación JavaFX respetando la arquitectura en capas del proyecto, creamos la clase administradora AdmonReporte.java dentro de com.example.basedatos.ADMON. Esta clase encapsula la llamada a Datos.getInstance() y devuelve el objeto JasperPrint listo para mostrarse:

src/main/java/com/example/basedatos/ADMON/AdmonReporte.java 
package com.example.basedatos.ADMON;

import net.sf.jasperreports.engine.JRException;
import net.sf.jasperreports.engine.JasperFillManager;
import net.sf.jasperreports.engine.JasperPrint;
import net.sf.jasperreports.engine.JasperReport;

public class AdmonReporte {
    private Datos datos;

    public AdmonReporte(){
        try{
            datos = Datos.getInstance();
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }

    public JasperPrint reporteCafes(){
        try {
            // Pasamos el archivo compilado con SQL, null en parámetros (usa el default "2026")
            // y la conexión JDBC (datos.getConexion())
            return JasperFillManager.fillReport("ReporteCafeSQL.jasper", null, datos.getConexion());
        } catch (JRException e) {
            System.err.println(e.getMessage());
        }
        return null;
    }
}

Checklist Final: ¿Dónde van los archivos en IntelliJ IDEA?

  • informacion.db, ReporteCafe.jrxml, ReporteCafe.jasper y ReporteCafeSQL.jasper deben estar directamente en la raíz del proyecto (afuera de src/, al mismo nivel que pom.xml).
  • En Jaspersoft Studio el Data Adapter usa la ruta completa al archivo (jdbc:sqlite:C:/.../baseDatos/informacion.db) y tiene el .jar de Maven cargado en la pestaña Driver Classpath.
  • En IntelliJ IDEA no importa en qué computadora se abra el proyecto: aunque el reporte .jrxml diga defaultdataadapter="informacionCafe", cuando llamas a JasperFillManager.fillReport("ReporteCafeSQL.jasper", null, datos.getConexion()) desde Java, Jasper ignora la ruta fija del adaptador y usa la conexión dinámica de tu clase Datos.java (MySQL o SQLite local).
