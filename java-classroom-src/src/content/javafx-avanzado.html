15. JavaFX Avanzado: TableView, Alertas y UI Dinámica

Al construir sistemas completos como BlockBusterUIX o el gestor de Café (BaseDatos), necesitamos ir más allá de botones y cajas de texto simples. En esta sección aprenderás a mostrar colecciones y jerarquías de herencia en un TableView, capturar números con Spinner, mostrar diálogos con Alert, alternar paneles dinámicos y compartir datos entre ventanas con el patrón Singleton.

1. TableView Estándar con PropertyValueFactory

Un TableView<T> muestra una lista de objetos en filas y columnas. La forma más directa de enlazar cada columna (TableColumn) con un atributo de tu clase POJO es mediante PropertyValueFactory<>("nombreAtributo"), que utiliza reflexión internamente para buscar el método getter correspondiente (por ejemplo, getSigla() o getNombre()).

Regla Crítica en module-info.java para Tablas

Para que PropertyValueFactory pueda leer los getters de tus objetos por reflexión sin lanzar un IllegalAccessException o dejar las celdas en blanco, debes abrir el paquete de tus modelos/controladores a javafx.base dentro de tu archivo module-info.java:

opens com.example.basedatos.POJO;
opens controlador to javafx.fxml, javafx.base;
TablaControler.java y Carrera.java (Proyecto BlockBusterUIX) 
package controlador;

import javafx.fxml.FXML;
import javafx.fxml.Initializable;
import javafx.scene.control.*;
import javafx.scene.control.cell.PropertyValueFactory;
import javafx.scene.input.MouseEvent;
import java.net.URL;
import java.util.LinkedList;
import java.util.ResourceBundle;

public class TablaControler implements Initializable {

    @FXML private TableView tablaCarrera;
    @FXML private ComboBox comboCarrera;
    @FXML private Label carreraSeleccionada;

    private LinkedList listaCarreras = new LinkedList<>();

    @Override
    public void initialize(URL location, ResourceBundle resources) {
        listaCarreras.add(new Carrera("LSIA", "Licenciatura en Sistemas de Información Administrativa"));
        listaCarreras.add(new Carrera("LART", "Licenciatura en Artes"));
        listaCarreras.add(new Carrera("LCC", "Licenciatura en Ciencias de la Computación"));
        listaCarreras.add(new Carrera("LISC", "Ingeniería en Sistemas Computacionales"));

        // 1. Definir las columnas y vincularlas con el nombre del atributo (busca getSigla() y getNombre())
        TableColumn tcSigla = new TableColumn<>("Siglas");
        tcSigla.setCellValueFactory(new PropertyValueFactory<>("sigla"));

        TableColumn tcNombre = new TableColumn<>("Nombre");
        tcNombre.setCellValueFactory(new PropertyValueFactory<>("nombre"));

        // 2. Asignar las columnas al TableView
        tablaCarrera.getColumns().setAll(tcSigla, tcNombre);

        // 3. Cargar los objetos de la LinkedList en la tabla y el ComboBox
        tablaCarrera.getItems().addAll(listaCarreras);
        comboCarrera.getItems().addAll(listaCarreras);
    }

    // Evento asignado en Scene Builder -> TableView -> On Mouse Clicked: #clicCarrera
    @FXML
    public void clicCarrera(MouseEvent mouseEvent) {
        Carrera carrera = tablaCarrera.getSelectionModel().getSelectedItem();
        if (carrera != null) {
            comboCarrera.setValue(carrera); // Sincroniza el ComboBox con la fila clicada
            carreraSeleccionada.setText("Seleccionado: " + carrera.toString());
        }
    }

    @FXML
    public void clicLimpiar() {
        tablaCarrera.getSelectionModel().clearSelection();
        comboCarrera.getSelectionModel().clearSelection();
        comboCarrera.setValue(null);
        carreraSeleccionada.setText("");
    }
}

2. TableView Polimórfico con Callback y SimpleStringProperty

¿Qué sucede cuando tu lista almacena una clase padre abstracta (como LinkedList<Producto> en BlockBusterUIX) que contiene subclases distintas (Juguete, ProductoDigital, Videojuego, Pelicula)? Si usas PropertyValueFactory para una columna como "Plataforma" (que solo existe en Videojuego), fallará en las filas que sean Juguete o Pelicula.

La solución empleada en VerInventarioControlador.java consiste en usar un Callback con SimpleStringProperty y verificar el tipo real de cada fila usando instanceof. Si el producto pertenece a esa subclase, hacemos downcasting y extraemos el dato; si no, mostramos un guion "-":

VerInventarioControlador.java (Proyecto BlockBusterUIX) 
package controlador;

import CodigoClases.almacen.Almacen;
import CodigoClases.modelo.*;
import javafx.beans.property.SimpleStringProperty;
import javafx.beans.value.ObservableValue;
import javafx.fxml.FXML;
import javafx.fxml.Initializable;
import javafx.scene.control.Label;
import javafx.scene.control.TableColumn;
import javafx.scene.control.TableView;
import javafx.scene.input.MouseEvent;
import javafx.util.Callback;
import java.net.URL;
import java.util.ResourceBundle;

public class VerInventarioControlador implements Initializable {
    @FXML private TableView tablaProductos;
    @FXML private Label labelProducto;

    private Almacen BlockBuster = Almacen.getInstance();

    @Override
    public void initialize(URL location, ResourceBundle resources) {
        // Columna común de la superclase Producto
        TableColumn tcsku = new TableColumn<>("SKU");
        tcsku.setCellValueFactory(new Callback, ObservableValue>() {
            @Override
            public ObservableValue call(TableColumn.CellDataFeatures param) {
                Producto objetoProducto = param.getValue();
                return new SimpleStringProperty(objetoProducto.getSKU());
            }
        });

        // Columna exclusiva de la subclase Juguete
        TableColumn tcmarca = new TableColumn<>("Marca");
        tcmarca.setCellValueFactory(new Callback, ObservableValue>() {
            @Override
            public ObservableValue call(TableColumn.CellDataFeatures param) {
                Producto objetoProducto = param.getValue();
                if (objetoProducto instanceof Juguete) {
                    Juguete objetoJuguete = (Juguete) objetoProducto;
                    return new SimpleStringProperty(objetoJuguete.getMarca());
                }
                return new SimpleStringProperty("-"); // No aplica para Películas o Videojuegos
            }
        });

        // Columna de la subclase intermedia ProductoDigital (aplica a Pelicula y Videojuego)
        TableColumn tctitulo = new TableColumn<>("Título");
        tctitulo.setCellValueFactory(new Callback, ObservableValue>() {
            @Override
            public ObservableValue call(TableColumn.CellDataFeatures param) {
                Producto objetoProducto = param.getValue();
                if (objetoProducto instanceof ProductoDigital) {
                    ProductoDigital pd = (ProductoDigital) objetoProducto;
                    return new SimpleStringProperty(pd.getTitulo());
                }
                return new SimpleStringProperty("-");
            }
        });

        // Columna exclusiva de Videojuego
        TableColumn tcplataforma = new TableColumn<>("Plataforma");
        tcplataforma.setCellValueFactory(new Callback, ObservableValue>() {
            @Override
            public ObservableValue call(TableColumn.CellDataFeatures param) {
                Producto objetoProducto = param.getValue();
                if (objetoProducto instanceof Videojuego) {
                    return new SimpleStringProperty(((Videojuego) objetoProducto).getPlataforma());
                }
                return new SimpleStringProperty("-");
            }
        });

        // Columna exclusiva de Pelicula
        TableColumn tcduracion = new TableColumn<>("Duración");
        tcduracion.setCellValueFactory(new Callback, ObservableValue>() {
            @Override
            public ObservableValue call(TableColumn.CellDataFeatures param) {
                Producto objetoProducto = param.getValue();
                if (objetoProducto instanceof Pelicula) {
                    return new SimpleStringProperty(String.valueOf(((Pelicula) objetoProducto).getDuracion()));
                }
                return new SimpleStringProperty("-");
            }
        });

        tablaProductos.getColumns().addAll(tcsku, tcmarca, tctitulo, tcplataforma, tcduracion);
        tablaProductos.getItems().addAll(BlockBuster.getInventario());
    }

    @FXML
    public void cliclProducto(MouseEvent mouseEvent) {
        Producto producto = tablaProductos.getSelectionModel().getSelectedItem();
        if (producto != null) {
            labelProducto.setText(producto.lineaTexto("|"));
        }
    }
}

3. Paneles Dinámicos, Spinner, Alert y Validación con Varargs

En AgregarProductoControlador.java (BlockBusterUIX) se combinan cuatro técnicas esenciales para formularios profesionales:

1. Paneles Dinámicos en un StackPane

Se colocan varios GridPane (panelJuguetes, panelVideojuegos, panelPeliculas) dentro de un StackPane. Para ocultarlos completamente y que no ocupen espacio en el layout, se invoca tanto setVisible(false) como setManaged(false).

2. Controles Numéricos Spinner<Integer>

Un Spinner no funciona hasta que le asignas su fábrica de valores en initialize() mediante:
new SpinnerValueFactory.IntegerSpinnerValueFactory(min, max, valorInicial).

3. Ventanas de Alerta (Alert)

Reemplazan a System.out.println en interfaces gráficas. Soportan tipos como AlertType.INFORMATION, WARNING, ERROR y CONFIRMATION. Con showAndWait() pausan el flujo hasta que el usuario pulsa ButtonType.OK.

4. Validación Limpia con Varargs (TextField...)

El método camposEstanLlenos(TextField... campos) recibe cualquier cantidad de TextField separados por comas y verifica en un solo bucle que ninguno esté vacío.

AgregarProductoControlador.java (Fragmento Clave) 
@Override
public void initialize(URL location, ResourceBundle resources) {
    comboTipoProductos.getItems().setAll(listaOpcionesTipo);
    ocultarPaneles();

    // Configurar rangos (mínimo, máximo, valor inicial) de cada Spinner
    edicionJuguete.setValueFactory(new SpinnerValueFactory.IntegerSpinnerValueFactory(1, 100, 1));
    anioVideojuego.setValueFactory(new SpinnerValueFactory.IntegerSpinnerValueFactory(1900, 3000, 2026));
    anioPelicula.setValueFactory(new SpinnerValueFactory.IntegerSpinnerValueFactory(1900, 3000, 2026));
    duracionPelicula.setValueFactory(new SpinnerValueFactory.IntegerSpinnerValueFactory(1, 500, 120));
}

public void ocultarPaneles() {
    panelJuguetes.setVisible(false);
    panelJuguetes.setManaged(false);
    panelVideojuegos.setVisible(false);
    panelVideojuegos.setManaged(false);
    panelPeliculas.setVisible(false);
    panelPeliculas.setManaged(false);
}

// Validación reutilizable con argumentos variables (Varargs)
private boolean camposEstanLlenos(TextField... campos) {
    for (TextField campo : campos) {
        if (campo.getText() == null || campo.getText().trim().isEmpty()) {
            Alert alertaError = new Alert(Alert.AlertType.WARNING);
            alertaError.setTitle("Campos incompletos");
            alertaError.setHeaderText("No se pudo agregar el producto");
            alertaError.setContentText("Completa todos los campos requeridos.");
            alertaError.showAndWait();
            return false;
        }
    }
    return true;
}

    stage.close();

4. Compartir Datos entre Controladores con el Patrón Singleton

Cuando abres una ventana secundaria (como AgregarProducto.fxml o VerInventario.fxml desde MainMenuControlador), JavaFX instancia un nuevo objeto controlador para esa vista. Si cada controlador hiciera new Almacen(), cada ventana tendría su propia lista vacía independiente.

En BlockBusterUIX, la clase Almacen aplica el patrón Singleton (constructor private y método estático Almacen.getInstance()) para garantizar que todas las ventanas lean y modifiquen exactamente el mismo inventario en memoria:

Almacen.java (Singleton compartido por toda la aplicación) 
package CodigoClases.almacen;

import CodigoClases.modelo.Producto;
import java.util.LinkedList;

public class Almacen {
    private LinkedList Inventario = new LinkedList<>();
    private static Almacen BlockBuster; // Única instancia estática

    // 1. Constructor privado: nadie fuera de esta clase puede hacer "new Almacen()"
    private Almacen() {
    }

    // 2. Punto de acceso global: crea la instancia solo la primera vez que se llama
    public static Almacen getInstance() {
        if (BlockBuster == null) {
            BlockBuster = new Almacen();
        }
        return BlockBuster;
    }

    public void agregarProducto(Producto producto) {
        Inventario.add(producto);
    }

    public LinkedList getInventario() {
        return Inventario;
    }
}
